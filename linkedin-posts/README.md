# منشورات LinkedIn — التميّز التشغيلي

قواعد دائمة لهذه السلسلة، حدّدها صاحب الحساب:

1. **اللغة:** العربية فقط. لا تُنتَج ملفات PDF أو نصوص منشور بالإنجليزية.
2. **الكتابة العربية الأصلية:** يُكتب النص العربي من المعنى مباشرة، لا من بنية إنجليزية. لا عناوين مقتضبة على نمط الشرائح الإنجليزية، ولا تسميات تتبعها نقطتان، ولا مصطلحات منقولة حرفيًا. كل شريحة جمل عربية تامة مترابطة بأدوات الربط العربية.
3. **المحرر العربي:** قبل كتابة أي نص عربي أو مراجعته، تُقرأ أحدث نسخة من ملف `Arabic_Editorial_and_Publishing_Agent.md` في Google Drive، وتُطبَّق قواعده كاملة، ومنها نقد خبير اللغة قبل التسليم.
4. **المصادر:** مراكز بحث عالمية وتقارير موثوقة ومجلات علمية محكّمة، لا مقالات موقع tamayuz10x.com.
5. **الدليل:** كل رقم في الشرائح يُربط بمصدره في ملف README الخاص بالمنشور، مع ذكر حدود الدليل في الشريحة الأخيرة.
6. **الهوية:** شعار تميّز 10X في الغلاف والشريحة الأخيرة، والشعار النصي في تذييل كل شريحة (المجلد `brand/`).
7. **النشر:** ينشر صاحب الحساب بنفسه. لا يُنشر أي شيء باسمه دون موافقة صريحة على كل منشور.
8. **الوتيرة:** منشور كل 3 أيام تقريبًا.
