1. **اللغة:** العربية فقط. لا تُنتَج ملفات PDF أو نصوص منشور بالإنجليزية.
2. **المحرر العربي:** قبل كتابة أي نص عربي أو مراجعته، تُقرأ أحدث نسخة من ملف `Arabic_Editorial_and_Publishing_Agent.md` في Google Drive، وتُطبَّق قواعده كاملة، ومنها نقد خبير اللغة قبل التسليم.
3. **المصادر:** مراكز بحث عالمية وتقارير موثوقة ومجلات علمية محكّمة، لا مقالات موقع tamayuz10x.com.
4. **الدليل:** كل رقم في الشرائح يُربط بمصدره في ملف README الخاص بالمنشور، مع ذكر حدود الدليل في الشريحة الأخيرة.
5. **الهوية:** شعار تميّز 10X في الغلاف والشريحة الأخيرة، والشعار النصي في تذييل كل شريحة (المجلد `brand/`).
6. **النشر:** ينشر صاحب الحساب بنفسه. لا يُنشر أي شيء باسمه دون موافقة صريحة على كل منشور.
7. **الوتيرة:** منشور كل 3 أيام تقريبًا.
