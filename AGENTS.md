# Tamayuz 10X Agent Instructions

Before researching, drafting, editing, or publishing Tamayuz 10X content:

1. Read `10X_Agent_AI_Master_Operating_Manual_AR.md` from `main` as the highest project operating reference.
2. For every article or case containing an Executive Summary / ملخص تنفيذي, also read and apply `10X_EXECUTIVE_SUMMARY_STANDARD_AR.md` before drafting or revising that section.
3. Treat the executive-summary standard as a mandatory Quality Gate, not optional style guidance.
4. The summary must make the case understandable to an executive who has not read the title or article. The default information order is:
   **problem → why it matters → intervention → operating-model change → documented results → 10X significance**.
5. The problem must be visible at the beginning. Do not lead with 10X theory, technology, abstraction, or a solution before the real-world problem is understood.
6. Apply the 20–30 second test in `10X_EXECUTIVE_SUMMARY_STANDARD_AR.md` before publication.

User instructions in the current task remain the highest authority.
