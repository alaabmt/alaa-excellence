# منصة التميّز — د. علاء أحمد

نسخة أولية V1 لموقع عربي ثابت (RTL) جاهز للرفع على GitHub Pages.

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع جميع الملفات الموجودة داخل هذا المجلد.
3. من Settings → Pages اختر:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. احفظ وانتظر ظهور رابط الموقع.

## أهم أماكن التعديل
- النصوص: داخل ملفات HTML.
- الألوان والتصميم: `assets/css/style.css`
- الجافاسكربت: `assets/js/main.js`
- الصورة الشخصية: أضفها إلى `assets/images/profile.jpg` ثم استبدل placeholder في `index.html`.
- روابط الكتب: `books.html`
- روابط الاختبارات: `personality.html`
- نموذج التواصل: `contact.html`

## المرحلة التالية المقترحة
- إضافة صورة وشعار حقيقيين.
- إضافة عناوين الكتب وروابط Amazon / IngramSpark.
- إضافة أول 5–10 مقالات حقيقية.
- ربط النشرة البريدية.
- ربط نموذج التواصل.
- إنشاء نسخة إنجليزية `/en/`.
